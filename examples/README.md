# Client configuration examples

Empty by design, for now.

Per-client examples are added only when a client has passed the five acceptance steps in
[`../docs/supported-clients.md`](../docs/supported-clients.md). Publishing a configuration
snippet we have not run would be a support claim we cannot back, and the whole point of the
compatibility matrix is that support is asserted from evidence rather than from a client
advertising Agent Plugins compatibility.

Each validated client gets a directory here containing its configuration snippet, the exact
plugin directory path, and the tested client version.

Candidate clients: Claude Code, Codex, Warp / Oz, Cursor, Opencode.

If you have run the acceptance steps, please
[file a compatibility report](https://github.com/flowcore-io/usable-agent-plugin/issues/new?template=compatibility_report.yml) —
including failures.

Note: examples are repository-only. They are excluded from release archives.
